# Installation

To install you first need to have [Obsidian ](https://obsidian.md/).

In Obsidian, create a new Vault (see [Obsidian Docs](https://obsidian.md/)). 

Clone the reposityory inside the vault's folder at ```vault-name/.obsidian/plugins```.

In Obsidian's setting allow for external plugin and enable Cardew.
