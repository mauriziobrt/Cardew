# Playing with physics

To test the environment in folder examples:
1. Load Graph "physics-graph.json"
2. Load Config "physics-graph-config.json"
3. Open Max patch "control-cardew.maxpat"

> ⚠️ **Attention you must add the property "Tracking" and set it to true to a node to make it send its continuous position to OSC.**

You can also test out a grid shape by loading "examples/grid-graph.json" and its config "examples/grid-graph-config.json". (Graphs are loaded by opening the left sidebar, if you use the provided Vault then you can open and close it with "cmd+u")
