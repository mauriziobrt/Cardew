# Selecting Nodes

Nodes can be selected in several ways, the most common one is by clicking on them with the mouse.
They can also be selected by navigating using **interaction modes** (see {doc}`interaction-modes`), by using the **filter view** (see {doc}`filtering`) or by using **OSC messages** (see {doc}`osc`).

# Selecting Multiple Nodes

Multiple nodes can be selected using rectangle selection or by pressing the  <kbd>shift</kbd> key while clicking on the nodes.
Rectangle selection is activated by clicking <kbd>alt/option</kbd> and dragging. Selected nodes will turn red. 

When selecting multiple nodes only the class for all elements can be edited in the metadata. It is also possible to paste a copied property to multiple nodes.s
