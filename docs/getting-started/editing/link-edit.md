# Editing Connections

Connections between nodes can be edited using the link view, that can be opened using the shortcuts <kbd>cmd/ctrl+o</kbd>.
Here users can alter the weight and direction of a link, or delete it. It's also possible to connect a node to any other node in the graph.

It's also possible to connect two nodes by selecting them, and pressing the <kbd>l</kbd> key. If more than two nodes are selected, all will be connected to the first selected node.
